## How I approach engineering

- **Security first:** enforce authorization on the server and validate inputs at API boundaries.
- **Data correctness:** design database-backed features around clear data flow, consistency, and safe failure handling.
- **Performance with evidence:** investigate request timing and database queries before applying caching, pagination, or query changes.
- **Production ownership:** build, test, deploy, monitor logs, and fix issues rather than stopping at a UI demo.
- **Communication:** document trade-offs and keep progress and blockers clear.
